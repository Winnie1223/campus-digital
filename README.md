campus-digital
浙江树人学院 计算机图形学 期中作业 校园数字孪生系统

项目说明
本项目基于 Three.js + HTML + JavaScript 开发浏览器端校园数字孪生三维交互系统，
包含校园建筑、植被、景观设施三维场景，实现多视角切换、建筑信息查询、图层控制、鼠标漫游等功能。
开发过程使用 Claude Code、Trae AI 辅助编程，3D模型采用腾讯混元3D生成GLB格式导入场景。

功能介绍
1. 三维校园场景渲染，包含教学楼、图书馆、宿舍楼、体育馆、喷泉、校门等模型
2. 透视/鸟瞰/北向三种视角平滑切换，支持快捷键操作
3. 鼠标悬浮提示、点击建筑查看详细信息面板
4. 建筑、文字标签图层手动显隐控制
5. 鼠标左键旋转、滚轮缩放、右键平移自由漫游
6. 场景粒子动画、实时光影、FPS与场景数量统计

运行方式
下载项目所有文件，用 Chrome / Edge 浏览器直接打开 index.html 即可运行，无需搭建后端、无需安装依赖。

技术栈
- 前端：HTML5 + CSS3 + JavaScript
- 3D引擎：Three.js 0.170.0
- 模型格式：GLB
- 开发工具：OpenCode、腾讯混元3D
- 版本管理：GitHub

作业备注
本项目为浙江树人学院《计算机图形学》期中考核作业
两人小组协作开发，遵循课程要求完成三维场景搭建、AI辅助开发、3D模型导入、交互功能设计、GitHub版本管理全部要求。
